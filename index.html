SnakeScale Notes

Set up SnakeScale Notes

SnakeScale Notes has no server and no account of its own. Your notes live in your own Google Drive, in a folder named SnakeScale Notes, and attachments live in an attachments subfolder of that same folder.

Sign in with Google is the only sign in. There is no SnakeScale Notes app password. Continue to the Google sign in step and approve access; SnakeScale Notes then connects Drive and creates your first notebook and starter note. Local copies on this device are encrypted with a random device key kept only on this device, which is not a login.

    Orphaned attachments
    Files in the attachments folder that no note, and no saved version of a note, still uses. Removing an image from a note can leave its file behind; this check finds those files so you can decide, one by one, what to keep. It runs only when you press the button; you can close Settings while it runs, and its results wait here when it finishes.

    Notifications

    Tasks can carry a reminder. When one comes due, this device shows a notification, generated here in the app: nothing about your tasks is sent anywhere to deliver it. Reminders fire while the app is open on this device; a reminder whose time passed while the app was closed arrives when you next open it.

    Notes can carry a reminder too, set from a note's own Reminder button. Note reminders follow the same rule: they fire on this device, while the app is open, and a missed one arrives when you next open it.

    When off, due tasks still show in your lists, but no notifications appear.
    When off, notes with reminders still show in your lists and in the Reminders view, but no notifications appear.

    Note history

    When a note changes and is saved, its previous saved version is kept. At the limit, the oldest version is removed as the newest is added. Use 0 to turn version history off.

    Web clipper

    Clip web pages into SnakeScale Notes, the way Evernote Web Clipper saves a page as a note with its source page attached. This app has no browser extension, so it uses a bookmarklet instead: a bookmark that runs a small clip script.

    1. Drag the button below to your bookmarks or favorites bar. In Edge, show the favorites bar first (View, or Ctrl+Shift+B).
    2. On any page, select text to clip just that selection, or select nothing to clip the page article.
    3. Click the bookmarklet. SnakeScale Notes opens in a new tab and files the clip as a note in your first notebook, with a link back to the source page at the top.
