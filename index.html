Set up SnakeScale Notes

SnakeScale has no server and no account of its own. First choose where your notes will live. You can change this choice only by resetting SnakeScale on this device; there is no migration tool yet.

With Google Drive, Sign in with Google is the only sign in. There is no SnakeScale app password. Continue to the Google sign in step and approve access; SnakeScale then connects Drive and creates your first notebook and welcome note. Local copies on this device are encrypted with a device key, which is not a login.

Your notes will live in a private GitHub repository that you own. The token is stored in this browser only, encrypted with the app password you choose here.

  1. On GitHub, open Settings, then Developer settings, then Personal access tokens.
  2. Create a token with the repo scope (classic token), or a fine grained token with Contents read and write access on your notes data repository.
  3. Paste the token below and choose an app password. You will type that password each time you unlock the app on this device.
If this repository does not exist yet, SnakeScale will offer to create it as a private repository in the next step.

Unlock SnakeScale Notes

Type your app password to decrypt your GitHub token on this device.

Forgot the password? The encrypted vault cannot be recovered without it. Use the reset button below to clear the vault on this device and set up again. Your notes in GitHub are not affected.

Google sign in is the only sign in for Google Drive storage. Notes and attachments use the same sign in. Google sign ins expire after about an hour; signing in again takes one click.
Your notes go in a folder named SnakeScale Notes in your own Google Drive. Attachments keep using the separate SnakeScale Notes Attachments folder.

Attachments

Images and files are stored in your own cloud account, in a folder named SnakeScale Notes Attachments. Your note files only keep a small reference to each attachment. You sign in with OAuth on the provider's own site; SnakeScale never sees your Google or pCloud password.

SnakeScale ships with the publisher Google client ID built in, so sign in works with nothing to fill in here. This field is an advanced override for testing, and for forks of SnakeScale that registered their own Google OAuth client. Clearing it returns to the built in ID. pCloud

Not signed in.
This test build needs the publisher pCloud client ID before sign in can work. The app owner creates the pCloud app once (free) and shares the ID for pasting here. End users of the finished app will never register a developer app or see this field; they will only click Sign in with pCloud, which sends them to pCloud to approve access. Setup steps are in ATTACHMENT_PROVIDERS_SETUP.md.

Apple note: iCloud Drive cannot be used directly by web apps, so Apple attachment storage is deferred to a possible future release.
