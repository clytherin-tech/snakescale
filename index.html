Set up SnakeScale Notes

Your notes will live in a private GitHub repository that you own. SnakeScale has no server and no account of its own. You connect it with a GitHub personal access token, and that token is stored in this browser only, encrypted with a password you choose here.

  1. On GitHub, open Settings, then Developer settings, then Personal access tokens.
  2. Create a token with the repo scope (classic token), or a fine grained token with Contents read and write access on your notes data repository.
  3. Paste the token below and choose an app password. You will type that password each time you unlock the app on this device.
If this repository does not exist yet, SnakeScale will offer to create it as a private repository in the next step.

Unlock SnakeScale Notes

Type your app password to decrypt your GitHub token on this device.

Forgot the password? The encrypted token cannot be recovered without it. Use the reset button below to clear the vault on this device and set up again with a new token. Your notes in GitHub are not affected.
